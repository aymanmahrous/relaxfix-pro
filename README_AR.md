# RelaxFix PRO - منصة الخدمات المنزلية الفاخرة

## 🏆 نظرة عامة

**RelaxFix PRO** هي منصة متكاملة لإدارة الخدمات المنزلية والصيانة، مصممة خصيصاً لسوق الإمارات. تجمع المنصة بين الاحترافية التقنية والفخامة البصرية بتصميم Art Deco عصري.

### المميزات الرئيسية

✨ **تصميم فاخر** - Art Deco بألوان ذهبية وسوداء عميقة  
🔐 **نظام أمان متقدم** - OAuth + JWT + Role-Based Access Control  
📱 **تطبيقات متعددة** - عملاء، فنيين، مديرين  
🗺️ **تتبع فوري** - تتبع الفنيين بالموقع الحي  
💰 **نظام دفع متكامل** - Stripe + المحافظ الرقمية  
⭐ **نظام تقييمات** - تقييمات وآراء العملاء  
🔔 **إشعارات ذكية** - Push، Email، SMS، WhatsApp  
📊 **لوحة تحكم متقدمة** - تحليلات وإحصائيات شاملة  

## 🏗️ البنية التقنية

### Frontend
- **React 19** - واجهة مستخدم حديثة
- **Vite** - بناء سريع وفعال
- **Tailwind CSS 4** - تصميم مرن
- **tRPC** - استدعاءات آمنة من النوع

### Backend
- **Node.js 22** - خادم عالي الأداء
- **Express 4** - إطار عمل خفيف
- **tRPC 11** - API آمنة من النوع
- **Drizzle ORM** - إدارة قاعدة البيانات

### Database
- **MySQL/PostgreSQL** - قاعدة بيانات موثوقة
- **Supabase** - خدمة قاعدة البيانات السحابية
- **19 جدول** - نموذج بيانات شامل

## 🚀 البدء السريع

### المتطلبات
- Node.js 22.13.0+
- pnpm 10.4.1+
- MySQL/PostgreSQL

### التثبيت

```bash
# استنساخ المشروع
git clone https://github.com/aymanmahrous/relaxfix-pro.git
cd relaxfix-pro

# تثبيت المكتبات
pnpm install

# إعداد متغيرات البيئة
cp .env.example .env.local
# عدّل .env.local بقيمك

# تشغيل خادم التطوير
pnpm run dev
```

افتح http://localhost:3000 في متصفحك.

## 🔧 أوامر التطوير

```bash
# التطوير
pnpm run dev          # تشغيل خادم التطوير
pnpm run check        # فحص النوع
pnpm test             # تشغيل الاختبارات
pnpm run format       # تنسيق الكود

# الإنتاج
pnpm run build        # بناء للإنتاج
pnpm run start        # تشغيل الخادم

# قاعدة البيانات
pnpm drizzle-kit generate    # إنشاء الهجرات
pnpm run db:push             # تطبيق الهجرات
```
